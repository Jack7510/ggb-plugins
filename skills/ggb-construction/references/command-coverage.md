# 固定 runtime 的命令覆盖边界

当前 runtime 为 **5.4.932.1**。数学语句交给原生 Algebra/CAS，不按数学命令白名单限制。脚本、三维对象及文件／网络副作用仍受既有边界约束；命令是否可用取决于具体重载、输入和运行结果。

- 官方目录：[All Commands](https://geogebra.github.io/docs/manual/en/commands/All_Commands/)。目录包含二维、三维和脚本等命令，不是本插件的支持清单。
- 仓库 `docs/command-catalog.json` 保存目录名称、日期和原始 HTML 摘要，不复制手册或逐重载声明支持。
- `pnpm coverage:commands` 使用六个跨域输入，经统一 build 和 headless preview 保存 GGB、报告、截图及 `coverage.json`。记录将程序调用、检查调用、通道、完整输入和证据路径关联起来。
- `delivered_examples` 只表示列出的调用所在程序成功交付及重载，不证明该命令全部重载、定义域或独立数学正确性。检查调用不等于交付该命令的对象。`not_tested` 表示没有本次证据，不能推断支持或不支持。

命令名称提取只是大写原生调用的检索提示，不是数学解析器。运算符、函数简写、别名和工具内部探针不计入目录覆盖。实际执行与核验以完整请求和报告为准。

遇到未记录命令，仍通过同一接口构造并独立核验。不得为了通过而删条件、改变题目或增加命令专用生产分支。复杂绑定、动态 CAS、任意域证明及其他平台仍有未验收范围。
