# 运行性能验收

日期：2026-10-16。基线：`d82abfa`。范围：本地已安装依赖的工作区实现；这些优化尚未发布。设计取舍见 [设计文档](ggb-plugins-design.md#81-性能证据与优化边界)，本文只记录方法、结果与限制。

## 测量方法

同一台 macOS 机器、Node.js 26.5.1、固定 GeoGebra 5.4.932.1 和匹配的 Chromium。对每个输入交替执行基线与优化实现，各五次，取端到端 build 中位数。两个实现共享相同安装资源；按原提交加载 browser、delivery、verify 与 doctor，其余生产模块在本次改动中未变化。没有同时运行其他回归测试。

只改变请求的 outputDir。程序、要求、检查、样本和容差保持不变。计时不包含安装下载、宿主模型、命令审批或系统浏览器启动。完整 doctor 另测，每侧三次。预加载阶段存在重叠，阶段时长不能相加代替总耗时。

首次三次复跑曾出现统计案例约 8% 的反向波动，因此最终使用交替测量。以下不是全平台性能保证，也不能用很小的差异宣称稳定收益。

逐次数据、输入摘要和优化实现摘要见 [性能数据](performance-results.json)。

## 成功输入的对比

| 案例 | 基线中位数 | 优化中位数 | 降幅 | 核验结果数／交互样本数 |
| --- | ---: | ---: | ---: | ---: |
| 圆与内接正六边形 | 2586 ms | 2174 ms | 15.9% | 50／2 |
| 奔驰定理说明图 | 2660 ms | 2238 ms | 15.9% | 81／2 |
| 统计、矩阵与符号假设 | 1877 ms | 1827 ms | 2.7% | 24／0 |
| 代数求解 | 1704 ms | 1675 ms | 1.7% | 18／0 |

全部构造、重载和交互阶段通过。基线与优化结果的初始快照按现有规范化及固定容差比较一致，核验结果数和样本数一致。几何输入的主要收益来自把下一份独立 applet 初始化与当前样本工作重叠；没有减少 applet、检查或鼠标样本。预加载最多额外持有一份页面；峰值内存尚未量化，不推导为所有规模的最优并发设置。

统计和代数的收益较小，仍可能包含测量波动。统计输入两次观察阶段的均值合计约为：CAS 就绪 511 ms、原生检查探针 140 ms、复杂值读取 49 ms、快照采集 55 ms。CAS 等待是当前较大成本；没有为了缩短它而跳过就绪判断或改用另一套计算引擎。

完整 doctor 中位数从 1444 ms 到 1430 ms，单次成本基本不变。Skill 复用本会话同一安装副本的成功结果，后续题目可以少执行一次完整 doctor，约省 1.4 秒。这是工作流收益，不计入上表的 build 降幅；新会话或环境变化仍执行完整 doctor。

## 门禁与资源回归

验证包括类型及结构错误、静态坐标冒充依赖、错误数学结果、灰区、未决 CAS、缺失探针、多输出遗漏、参数越界／退化、定义篡改、取消、清理失败、提交前后强制退出，以及预览文件复核。

新增检查覆盖：

- 字段级差异仍拒绝数学、依赖和样式变化，缺失或重复对象不能通过。
- 文本默认属性能往返；显式不兼容样式仍失败，动态文字仍随点联动。
- 重载失败保留构造和重载报告；定义变化另存字段差异，仍无正式交付。
- 成功与可处理失败保存非负阶段计时；计时不参与数学判定。
- 预加载期间发生错误、取消或清理失败，统一关闭会话，不把失败的预加载当作通过。
- 鼠标操作前的绘制等待有时限；绘制不就绪时失败并清理。

执行类型检查、构建、离线测试、真实浏览器与故障／启动回归，以及 Skill 结构校验。具体运行输出与原始性能数据保存在工作区 output/performance-final/；该目录按仓库规则不提交。

## 复现入口

开发脚本 [benchmark.mjs](../scripts/benchmark.mjs) 只用于离线性能验收，不进入插件运行管线。先执行 pnpm build，并准备固定 runtime。传入同一批请求文件，例如：

```sh
node scripts/benchmark.mjs --baseline d82abfa --repeats 5 \
  --output output/performance-benchmark \
  hexagon=/absolute/path/to/hexagon-request.json \
  mercedes=/absolute/path/to/mercedes-request.json \
  statistics=tests/fixtures/statistics.json \
  algebra=tests/fixtures/algebra.json
```

脚本保存输入摘要、各次耗时、核验覆盖、交付路径和 comparison.json。四个基准输入中的前两个来自本次会话保存的案例，未加入生产题型模板；在另一工作区复现时需提供相同请求。脚本读取指定 Git 基线的模块，在内存中擦除 TypeScript 类型并重定向到本包依赖，不创建额外 checkout 或运行时依赖。比较不同引擎或协议的提交需另行设计实验，不能直接沿用本次结论。
