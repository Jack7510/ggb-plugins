# GeoGebra Construction 0.8.4

**状态：包装与验证完成，npm 发布待认证。** 0.8.3 的 DSH 包未公开发布；
0.8.4 汇总 0.8.3 与本次修复，请求协议、固定 GeoGebra 运行时和核验门禁不变。

## 主要变化

- 原生执行失败提示覆盖位置参数 `Polygon(A,B,C)`、native 下标/方括号/嵌套参数，
  以及 `Round(...)` 大小写误用；提示不改写 source、失败分类或构建预算。
- Worker 与参考明确：核验使用未取整的残差和面积和，`round` 只处理显示副本；
  整数边数构造和合法性检查保持不变。
- 交付 `verification.json` 改为 compact JSON。同一份 18 对象、每阶段 87 项
  检查的报告由约 1.47 MiB 缩到约 647 KiB，低于 DSH 1 MiB report 限制；
  运行诊断保留 pretty 副本，核验内容、GGB/预览/manifest 与回执不变。
- 宿主 artifact 超限错误补充 kind、实际字节和上限，便于定位。

## 发布状态

`npm publish` 已尝试，但当前 `~/.npmrc` 的认证身份不可用：

- `npm whoami` 返回 `E401 Unauthorized`；
- `npm publish ... --access public` 返回 `E404 ... could not be found or you do not
  have permission`。

因此 registry 仍是 `ggb-plugins-dsh@0.8.2`，DSH 安装说明暂保留 0.8.2。
需要用包 owner 账号重新登录（或更新有 publish 权限的 granular token）并完成
2FA 后，先把 `dsh/README.md` 更新为 0.8.4 并重新打包 DSH（`INSTALL.md`
随文档进入包），再执行：

```sh
npm publish <重新打包后的 pluginDirectory> --access public
npm view ggb-plugins-dsh version
```

上表 SHA 对应本轮候选包；重打包后以新 SHA 为准。本轮未创建 Git 标签或
GitHub Release。
