# GeoGebra Construction 0.8.0

This release packages the same GeoGebra execution and verification pipeline for two local plugin ecosystems:

- Codex: `ggb-plugins-0.8.0.zip`, with the portable plugin manifest and marketplace entry.
- DeepSeek Harness: `ggb-plugins-dsh-0.8.0.tgz`, with the npm bundle manifest, Cordis patch and native skill provider.

Each package carries its own compiled CLI, Skill, references, viewer and setup scripts. The DSH package no longer searches Codex caches or another checkout. Install through the target host, then run setup-plugin in the installed copy. Runtime and browser downloads remain separate and pinned.

Request protocol 2, M6 delivery format and GeoGebra 5.4.932.1 remain unchanged. This is local distribution, not approval by either public plugin directory. See docs/dual-ecosystem.md and docs/dual-ecosystem-validation.md for installation commands, evidence and tested client boundaries.
