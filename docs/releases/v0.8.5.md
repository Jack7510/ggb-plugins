# GeoGebra Construction 0.8.5

**状态：已发布。** npm `ggb-plugins-dsh@0.8.5` 与 GitHub Release `v0.8.5`
均已上线。本版修复 DSH 0.2.1-rc.3 无法安装 0.8.4 的兼容性阻断，不改变请求
协议、GeoGebra runtime 或核验门禁。

## 主要变化

- DSH 桌面 bundle 的 `engines.dsh` 从固定 `0.2.1-rc.2` 改为
  `>=0.2.1-rc.2 <0.2.2`。0.8.4 会被当前 DSH `0.2.1-rc.3` 拒绝；0.8.5 已用
  隔离 `web` profile 完成安装、runtime 准备和 doctor。
- 修复 `setup-plugin` 在 DSH profile 内重复执行 pnpm 安装、误入 profile
  workspace 锁文件而失败的问题：已由 `dsh plugin add` 安装的依赖直接复用。
- 受限 SDK Server 入口仍只接受已验证的 `0.2.1-rc.2`，不随桌面范围的放宽而改变。
- npm 关键词修正 `deepeek-harness` 拼写并补充数学教育相关词，便于搜索。
- 新增 [DSH Discover 索引](../market/index.json) 与
  [社区上架文案](../community-submission.md)；README 安装命令同步到 0.8.5。

- `pnpm test`：主套件 207 项与 offline execution 42 项全部通过。

- 在同一安装副本执行 `setup-plugin`：下载固定 GeoGebra 5.4.932.1、找到

  为 `>=0.2.1-rc.2 <0.2.2`；同一 `web` profile 的 setup 与 doctor 再次通过。

## 安装

```sh
profile=desktop   # DSH 插件中心/Web 宿主改为 web
dsh plugin --profile "$profile" add ggb-plugins-dsh@0.8.5
node ~/.dsh/profiles/$profile/node_modules/ggb-plugins-dsh/scripts/setup-plugin.mjs
```

离线或需要使用 Release 资产时，下载 `ggb-plugins-dsh-0.8.5.tgz` 后执行：

```sh
dsh plugin --profile web add /absolute/path/ggb-plugins-dsh-0.8.5.tgz
```

Codex 用户下载 `ggb-plugins-0.8.5.zip` 和 `.zip.sha256`，按
[Codex 安装说明](../../codex/README.md) 校验并安装。
