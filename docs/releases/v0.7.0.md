# GeoGebra plugin 0.7.0

M7 adds a reproducible fixed-runtime command coverage inventory, installation updates and fresh Codex client acceptance. Mathematics continues through the existing native Algebra/CAS execution and delivery pipeline, with no new command dispatch or runtime dependency.

The ZIP contains the compiled CLI, Skill, coverage boundaries, local viewer and setup scripts. Run setup-plugin after installation. Request protocol 2 and M6 delivery format remain unchanged.

Coverage distinguishes the official command catalog from delivered examples and untested commands. It does not claim every command overload or platform has been accepted. See the repository's M7 validation record for headless screenshots and client evidence.
