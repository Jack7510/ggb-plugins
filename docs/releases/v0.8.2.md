# GeoGebra Construction 0.8.2

本版本准备分发当前代码仓的 Codex ZIP 与 DSH TGZ。请求协议仍为 2，交付格式仍为 M6，固定 GeoGebra 运行时仍为 5.4.932.1。版本准备与本机安装不等于 GitHub Release 已发布。

## 主要变化

- 使用本机 Chrome／Edge 执行核验与预览，不再下载 Chromium；doctor 报告实际浏览器。
- 交付目录与 GGB 文件按题目命名，可用 title 指定；重名自动追加编号，不覆盖已有交付，旧 result.ggb 仍按清单复核。
- 构建页与最终预览跟随请求语言；页面语言不符会阻止交付。成功后用系统默认浏览器打开同一 GGB。
- 最终预览默认显示工具栏和代数窗口，并占满页眉、页脚之外的浏览器空间；窗口变化时原生 applet 同步调整尺寸。自动核验布局与正式文件保持不变。
- 统一引擎依赖证据、外观归属与相关采样覆盖；保留定义有效性、固定容差、参数往返、重载和提交门禁。
- 所有新建 ID 与显式 outputs 共用保留字及内置名称保护；已有基线标签保留原始身份，实际输出仍须经过引擎核验。
- 可变量默认用滑块或可拖点，按相关参数变化核验。具体构法与聚合检查放在 references/patterns.md，两种封装均携带该参考。
- 精简 Skill 与 Worker 的重复及冲突配方。文件型 Agent 按需读取契约；受限 Worker 使用宿主提供的工具参数定义。体量检查覆盖两入口的行数、字节量、参考预算和链接。
- 文档按职责与宿主分区，历史阶段记录进入归档；保留原证据与适用范围。
