# GeoGebra Construction 0.6.0

M6 为统一原生 GeoGebra 管线增加列表／矩阵结构核验、显式 CAS 假设、完整多输出核对和滑块参数采样。保留 M1 与 M5 回归，不增加题型或逐命令包装。修复独立圆锥曲线的一致性门禁，并使用原生异步接口加载数学模块。

本地验证：136 项测试通过，真实浏览器验证全程 headless。源码 doctor、打包和 Skill 校验通过。全部二维命令覆盖及其他客户端兼容性尚未完成验收。

下载 `ggb-plugins-0.6.0.zip` 和同名 `.sha256` 文件，校验后解压，按包内 README 安装。ZIP 包含编译 CLI 和 Skill，不包含 GeoGebra、Chromium 或用户产物。

Codex 也可从固定 Git 版本安装：

```sh
codex plugin marketplace add Jack7510/ggb-plugins --ref v0.6.0
codex plugin add ggb-plugins@ggb-plugins-local --json
```

随后在返回的安装缓存路径执行 `node <installed-plugin>/scripts/setup-plugin.mjs`。需要 Node.js 22+、pnpm 11、curl、unzip 和安装阶段的网络连接。其他本地工具可调用包内 `dist/src/cli.js`，无需 Codex 专用运行时；Skill 自动发现方式由各工具决定。

请求继续使用协议 2；旧交付目录须重新构造以补齐 M6 证据。CAS 保存当次结果，符号结论只在声明假设下成立；有限参数样本不等于全域证明。
