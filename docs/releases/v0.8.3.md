# GeoGebra Construction 0.8.3

**状态：未公开发布。** 本版本将当前代码仓封装为新的 Codex 本机插件。请求协议、固定 GeoGebra 运行时及数学核验门禁保持不变。

## 变化

- DSH 执行器协议 3、构建回执 schema 2；宿主按 `src/host-protocol.ts` 对接。
- Codex 包声明安装引导 Skill，负责当前安装副本的依赖准备与 doctor 检查。
- 安装说明区分本地包与远端已发布标签，删除不存在的 0.8.2 Codex 下载入口。

- Applet 原生界面固定为英文，代数区使用英文命令名。
- 预览页面的状态与按钮继续使用请求的 locale；题目、Text 和对象文字保留原文。
- 自动核验和最终展示使用相同的 Applet 语言设置，不增加语言配置分支。

## 分发与安装

Codex 包为 ggb-plugins-0.8.3.zip，DSH 包为 ggb-plugins-dsh-0.8.3.tgz，各附 SHA-256 文件。两包从同一源码构建；本轮只部署本机 Codex，不更新 DSH npm 包、不创建 Git 标签或 GitHub Release，也不提交官方插件目录。

安装步骤见 [Codex 安装说明](../../codex/README.md)。本机验收及资产摘要见 [0.8.3 验证记录](../../codex/docs/v0.8.3-validation.md)。用户应在新会话中使用新版本；当前会话已经加载的旧 Skill 不保证自动刷新。

安装引导的隔离验收与首题交付证据见 [安装验收](../../codex/docs/codex-onboarding-validation.md)。
该记录区分 CLI、全新会话与桌面设置入口的覆盖范围，不替代历史本机部署记录。
