# M2 验收记录

日期：2026-10-16。范围：可组合文字题程序、统一执行与核验、仓库内 Skill，以及真实 GGB 交付。M3 故障验收、doctor 和 M4 插件安装发布尚未完成。

## 实现与环境

继续使用一个 TypeScript 包，无新增运行依赖。环境为 macOS 15.7.3 arm64、Node.js 26.5.1、pnpm 11.7.0、TypeScript 7.0.2、Playwright 1.64.1、Chromium revision 1248、GeoGebra 5.4.932.1。

构图请求由宿主 Codex 生成。CLI 接受有类型的操作、对象引用、来源要求及验收谓词。编译器拒绝循环、未知引用、类型错误、任意脚本和不支持的方法。执行器调用真实原生命令；验证器消费点坐标、直线系数、圆参数、XML 依赖和样式事实。

数值比较采用固定容差；对象身份和依赖按语义精确比较。原生命令别名归一化，数值参数从构造 XML 读取，避免显示文本舍入损失。默认取景保持横纵单位比例，交互检查使用实际鼠标拖动和原生缩放按钮。

## 保证边界

有限命令组合和采样检查不能证明任意数学命题。能力受当前原语与谓词约束。工具核对来源片段和结构覆盖，不能自动证明自然语言条件提取完整；这一责任属于 Codex 的题意分析与自审。

本轮测试使用仓库内 Skill 说明生成新题请求，不代表已经通过正式插件安装或自动 Skill 发现验收。未验证图片、外部 GGB 续题、三维、复杂布局、无限区间性质和其他操作系统。原 M1 的专用执行和验证代码已移出生产路径，旧交付目录需重新生成。
