# 圆周角与圆心角

- 模板：`inscribed-angle`
- 源请求：[05-inscribed-angle.json](../../examples/geometry-benchmark/05-inscribed-angle.json)
- 适用：圆、弧、路径点、角度关系。

## 构图要点

先建圆心 O 与圆，再在圆上放 A、B、C。C 必须约束在不含 A、B 的同一段有效弧上，使用路径点而不是任意自由点；圆心角取不超过 180° 的那一个。角度关系用独立计算或原生关系核验，不靠视觉判断。

## 核验点

- A、B、C 与圆的关系，C 的路径范围与端点排除。
- 圆心角、圆周角的实际测量值及两者比值。
- 拖动 C 后关系仍成立；采样要覆盖有效弧段，而不是只测一个位置。
- 退化位置（C 与 A 或 B 重合）要有定义状态说明，不能静默通过。

## 课堂用法

拖动 C 让学生观察圆周角随位置变化但保持为圆心角的一半。插件只呈现构图与有限样本，不把样本外推成一般证明；证明仍需课堂完成。
