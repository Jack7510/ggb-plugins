# 椭圆焦点

- 模板：`ellipse-focus`
- 源请求：[ellipse-focus-triangle.json](../../examples/v2-cases/ellipse-focus-triangle.json)
- 适用：椭圆、焦点、焦点三角形、参数范围。

## 构图要点

椭圆方程中的参数 a 用滑块控制，范围 2≤a≤3；两个焦点用原生 `Focus` 命令生成并声明依赖。过第一个焦点的弦与第二个焦点组成三角形，弦端点用路径点约束在椭圆上。不要手算焦点后写成固定坐标。

## 核验点

- 椭圆方程与参数范围正确，a 变化后焦点仍由同一关系生成。
- 两焦点坐标满足椭圆定义，焦点三角形顶点都在椭圆上。
- 拖动或改变 a 后，距离和、定义依赖与样式仍成立。
- 参数边界与退化位置要有样本或明确未验证说明。

## 课堂用法

拖动 a 观察焦点移动与弦三角形变化；讨论椭圆定义与焦点三角形的性质。插件提供可操作对象和有限样本证据，不代替证明。
