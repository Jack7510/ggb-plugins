# 内切圆

- 模板：`incircle`
- 源请求：[02-incircle.json](../../examples/geometry-benchmark/02-incircle.json)
- 适用：三角形、角平分线、内心、内切圆、切点。

## 构图要点

三条内角平分线用原生命令，内心取交点，内切圆以内心为圆心、到边的距离为半径。三个切点由原生关系生成并声明依赖，不要手算后写成固定点。

## 核验点

- 角平分线依赖对应顶点与边。
- 内心是三条角平分线的交点。
- 内切圆与三边相切，切点确实落在边上。
- 拖动顶点后半径、切点和相切关系仍成立。

## 课堂用法

拖动顶点观察内心位置与内切圆大小变化；与“外接圆”案例对照，讨论内心与外心的不同构造。
