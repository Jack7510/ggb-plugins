# 动点与滑块

- 模板：`moving-slider`
- 源请求：[slider-polygon.json](../../examples/v2-cases/slider-polygon.json)
- 适用：滑块参数、多边形、参数往返。

## 构图要点

滑块控制多边形边数时，边数必须是可回溯的整数参数；多边形的顶点列表随参数重算，避免只改一部分顶点留下未定义的旧对象。参数变化后要恢复原值，检查对象是否仍定义。

## 核验点

- 滑块的范围、步长和当前值。
- 参数往返（例如 3 → 12 → 3）后，多边形对象与边数一致。
- 旧顶点、边和附属对象没有变成隐藏的未定义残留。
- 拖动或改值后，真实依赖仍在，不以赋值代替移动。

## 课堂用法

让学生拖动滑块观察多边形形状变化，再回到初始值检查图形是否复原。适合讨论参数化与对象生命周期；不要把参数往返成功误说成对所有实数成立。
