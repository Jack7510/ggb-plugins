# 函数图像

- 模板：`function-graph`
- 源请求：[parabola.json](../../examples/v2-cases/parabola.json)
- 适用：函数、方程、圆锥曲线、关键点。

## 构图要点

函数或方程优先用原生命令表达；需要固定坐标时，只对题目给定的值使用固定坐标。关键点（焦点、顶点、交点）用原生关系命令生成，并声明它们依赖的输入。切线、中垂线等关系要引用真实对象。

## 核验点

- 表达式与题目一致，定义域和分支明确。
- 关键点的坐标、类型和依赖正确。
- 代数视图与绘图视图表达同一对象；样式要求单独检查。
- 参数变化或拖动后关系仍成立；有限采样不声称覆盖全域。

## 课堂用法

适合函数图像与解析几何的衔接：先看图像，再拖动参数观察关键点移动。插件不给出题目答案，只保留条件与核验证据。

## 产物与报告

```sh
node scripts/render-report.mjs --delivery <交付目录> --output function-graph.html
```
