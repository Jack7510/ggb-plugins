# 数学教师试用与反馈方案

## 目标与范围

邀请 10–15 位数学教师，观察从安装到生成首个可拖动 GeoGebra 文件的过程，判断结果能否用于备课或课堂。先使用已发布版本和对应安装说明；记录版本，不把开发中的功能当成已交付能力。试用覆盖二维作图，不要求插件给出答案或证明。

招募初中、高中教师及不同 GeoGebra 熟练度的参与者。人数是招募目标，不是统计代表性样本；结果同时报告人数、分母和原话，不推断总体市场规模。

## 邀请文字

> 我们正在试用一个把二维数学题变成可交互 GeoGebra 图的工具，想邀请数学老师用自己的备课题目体验。首次约 30–45 分钟，一周后可选择参加 5 分钟回访。我们关注安装、作图和课堂使用是否顺手，不考察您的操作能力。您可以随时停止，也可以不提供题目和文件。参与和回访均自愿；如希望参加，请私信组织者约时间。

由组织者选择合适渠道和联系方式后发送，不自动群发。不要收集学生姓名、成绩或其他可识别信息；题目及截图先由参与者自行脱敏。

## 首次试用流程

1. **准备（5 分钟）：**说明工具的范围、参与自愿、记录方式和是否允许回访。记录受访者代号、任教学段、GeoGebra 熟练度、系统、DSH 与插件版本。联系方式如需保存，应与观察表分开保管。
2. **发现与安装（10–15 分钟）：**让老师按公开安装说明操作，观察是否找到正确宿主、安装包、完成环境准备和重启。出现卡点先记录，再按需协助，并标记协助类型；不要将协助完成记为独立完成。
3. **完成第一题（10–15 分钟）：**优先使用老师自带的二维题；没有时使用示例：“作三角形 ABC，取 AB 的中点 M，连接 CM。”请老师打开 GGB、拖动 A 或 B，观察 M 是否仍为中点，并阅读检查结果。示例只用于试用，不代表覆盖所有题型。
4. **教学判断（5–10 分钟）：**请老师判断是否愿意用于自己的备课或课堂，指出必须修改之处；若希望继续，尝试用自然语言提出一项修改。记录生成失败和未检查的条件，不代替教师判定数学正确性。
5. **一周后自愿回访（约 5 分钟）：**问是否在真实任务中再次使用、用于什么、没用的原因，以及是否愿意推荐给同事。不要把口头意愿算成实际使用。

任何参与者可跳过步骤；无法安装也照常记录原因并结束，不要求其提交个人配置或密钥。

## 观察记录模板

每位参与者一份，使用代号；不在公开仓库保存原始访谈、个人数据或未授权题目。

```text
代号 / 日期：
学段 / GeoGebra 熟练度：
系统 / DSH 版本 / 插件版本：
题目类型与教学目标（脱敏概述）：
找到安装入口：独立 / 协助 / 未完成；卡点：
安装包：独立 / 协助 / 未完成；卡点：
环境准备和重启：独立 / 协助 / 未完成；卡点：
首题：独立完成 / 协助完成 / 未完成；耗时及起止口径：
GGB 能否打开：是 / 否 / 未检查
拖动关键点后关系：符合 / 不符合 / 未检查；依据：
教师判断能否用于课堂：可直接使用 / 修改后可用 / 不能 / 未判断
老师要求的修改与实际结果：
具体障碍、错误提示和参与者原话：
一周后：实际再次使用 / 未使用 / 未回访；原因：
是否同意回访：是 / 否；是否同意公开引用或案例：单独确认
```

耗时从参与者开始对应步骤计至完成或停止；注明下载等待和组织者协助。安装失败者仍计入受邀且开始试用的分母；未回访者不算作“未再次使用”。

## 访谈问题

- 您通常怎样准备这类图？今天最想完成什么教学任务？
- 哪一步最难理解或最耗时？您原本预期会发生什么？
- 这张图能否用于课堂？哪些数学关系、标注或视觉效果需要修改？
- 检查结果有没有让您更容易判断是否可信？哪里仍不清楚？
- 您什么时候会再次使用？如果不会，主要原因是什么？

不要暗示必须给正面评价。访谈结束时复述关键问题，请参与者确认是否理解正确。

## 汇总与处理

每周统计：开始试用人数、独立安装完成数、首题独立完成数、首题经协助完成数、能打开 GGB 数、教师认为可直接或修改后用于课堂的人数、一周内实际再次使用人数及回访人数。每项注明分母和未观察数量，不把下载量当用户数。

将障碍按发现、安装、环境准备、题意理解、数学核验、交付、课堂使用分类；按影响人数和严重程度排序。每条保留复现条件、版本和状态，选择最常见的 2–3 个障碍处理；将数学正确性错误优先于外观建议。获得明确许可后才公开原话、题目、截图或 GGB。问题可由组织者脱敏后提交至 [项目 Issues](https://github.com/Jack7510/ggb-plugins/issues)。
