## 安装与运行时来源

稳定 marketplace 来源为 ~/.codex/local-marketplaces/ggb-plugins-v0.8.3，实际安装目录为 ~/.codex/plugins/cache/ggb-plugins-local/ggb-plugins/0.8.3。注册来源和安装通过 Codex 插件命令完成，不手动修改插件注册表。旧 marketplace 目录保留；Codex 更新安装时清理了旧版缓存。

新安装副本通过锁文件安装生产依赖，使用本机 Google Chrome。官方 GeoGebra 下载缓慢，本轮主动终止下载，再将当前仓库已准备的固定 .runtime 复制为安装目录中的独立副本。复制前核对 version、url、sha256 与 runtime.lock.json 一致；元数据还含正常的 codebase 路径字段。随后从安装目录执行 doctor、构图及预览，未引用开发仓库的 CLI 或 DSH 缓存。

因此，本轮验证的是本机部署及安装副本运行，不是首次联网安装、官方归档重新下载或其内容摘要重新认证。setup.log 保留被终止的下载；独立 doctor.json 记录最终就绪检查。
