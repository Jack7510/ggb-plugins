## 教学预览补充验收

最终展示页默认打开工具栏与代数窗口，使用独立容器和原生 setSize 响应视口，不重复自动缩放。图形模式按交付文件原视野等比例适配，纯代数模式保留代数视图；不自动聚焦输入框或展开占据画布的输入键盘。自动核验页仍采用固定尺寸，文件不回写。

受影响检查包括契约与体量 6 项、服务边界 1 项，以及标题、中英文和响应式布局 3 项浏览器回归。首轮的布局项失败于错误工具栏定位；改用固定 runtime 的真实 toolbarPanel 节点后，发现了注入容器受部署器改写与重复缩放的问题。修复独立容器与缩放后，三项浏览器回归通过。随后去掉自动输入焦点时，布局变动与只读 XML 审计产生竞态；等待原生布局绘制完成再发出就绪、在窗口重排后核对快照，最终只复跑受影响的布局项并通过。没有放宽原 XML 不变条件或数学容差。

最终布局项覆盖图形与纯代数两种模式，在 1280×900、820×680、1920×1080 下检查面板、原生 frame 尺寸、页面无溢出及主要展示空间；图形用例还检查整个半径为 3 的圆仍在可见视野内且两轴比例相同。每个尺寸对照数学快照，结束后核对正式 GGB 摘要不变，截图均保留。具体日志与失败诊断见 [output/preview-layout](../../output/preview-layout/)。

两种新包重新生成并核对摘要，本机安装更新后 37 个分发文件再次一致，安装器 doctor 的 smoke 与 casSmoke 通过。证据为 codex-preview-package.json、dsh-preview-package.json、preview-install.log、preview-setup.log、preview-provenance.json；最终可见预览的实际打开依据为 preview-display.log 中的就绪 JSON。没有重复运行全量检查或新建宿主会话，也没有发布 GitHub Release。
